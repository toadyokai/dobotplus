开发环境

使用该工具集开发插件必须的配置环境包括 NodeJs、Pnpm。

推荐在Windows10及以上系统开发。

Node.js​

该工具集基于 NodeJS 20.13.1 版本进行开发，请安装 v20 以上的 NodeJS 版本进行开发。
在命令行中执行以下命令可查看node版本号 ‼️ ❗

node -v

Pnpm​

该工具集使用 pnpm 管理 monorepo 依赖。相比 npm / yarn，pnpm 通过硬链接共享依赖，安装更快、占用磁盘更少，也是 CLI 初始化插件模板时的默认包管理器。

安装 Node.js 后，执行以下指令：

npm install -g pnpm

在命令行中执行以下命令可查看 pnpm 版本号：

pnpm -v

AI 编程​

借助 AI 编程 IDE，开发者可以通过 Agent 对话、Requirements.md 与 Skills（如 /dobot-plus）快速生成插件代码，显著缩短从协议文档到可运行插件的周期。以下 IDE 均基于 VS Code 内核，可安装相同的扩展插件。

优先级IDE说明
1Cursor首选，Agent Skills 生态成熟，AI Agent 能力强
2Trae备选，国内访问友好，内置多种免费 AI 模型
3VSCode传统开发，无 AI 辅助或习惯纯手动编码时使用

下文分别介绍 Cursor 与 Trae 的安装方式；VSCode 的安装与推荐插件见后文。

Cursor​

Cursor 是基于 VS Code 的 AI 编程 IDE，界面与插件生态与 VS Code 相近，适合在本地借助 AI Agent 辅助开发 Dobot+ 插件（例如通过 Agent Skills 将 Requirements.md 转为功能代码）。

下载安装：

  1. 打开 Cursor 官网，按操作系统下载安装包
  2. 按安装向导完成安装并启动 Cursor
  3. 使用 File → Open Folder 打开插件项目目录

首次使用可按提示登录账号。开发 Lua、i18n 等场景时，可安装与 VS Code 相同的推荐插件（见下文 VSCode 章节），以获得代码补全、检查与翻译等能力。

Trae​

Trae 是字节跳动推出的 AI 编程 IDE，同样基于 VS Code 内核，支持 VS Code 插件市场。国内用户推荐使用 Trae 国内版（trae.cn），海外用户可使用 Trae 国际版（trae.ai）。两个版本账号与内置模型相互独立，请按需选择。

下载安装（以国内版为例）：

  1. 打开 Trae 官网，下载对应操作系统的安装包（支持 Windows / macOS）
  2. 运行安装程序并按向导完成安装
  3. 首次启动时选择语言与主题，使用手机号注册并登录
  4. 可选：在设置中从 VS Code / Cursor 导入已有插件、主题与快捷键
  5. 使用 文件 → 打开文件夹 打开插件项目目录

Trae 内置 Builder、Chat 等 AI 模式，可用于代码补全、问答与项目搭建。借助 AI 开发 Dobot+ 插件时，可将项目根目录的 Requirements.md 作为上下文，让 AI 协助生成 Lua、UI 等代码；完整的一键 /dobot-plus Agent Skill 流程目前以 Cursor 为首选。Lua、i18n 等开发场景同样建议安装下文 VSCode 章节中的推荐插件。

VSCode​

开发者可以根据使用习惯选择自己习惯的IDE工具。推荐使用VSCode用于本地开发。
该工具在开发过程中会利用一些 VSCode 插件提高开发效率，在使用 VSCode 进行开发时，会有对应的建议弹窗。
开发者使用 VSCode 进行开发时，建议安装 VSCode 推荐的插件。

  • lua

    • 该插件是调试开发lua的首选，具备代码检查、自动补全和代码提示的功能

  • lua-helper

    • 使用 GO 开发的一款 lua 开发工具，可以执行代码的检查、补全、提示和格式化
    • 功能稳定

  • i18n

    • 在 vscode 中提供可视化的翻译资源编辑工具
    • 联网状态在可以一键翻译文案
    • 在组件内，可以预览文案
